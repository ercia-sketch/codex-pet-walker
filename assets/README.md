# 스프라이트 파일 준비

이 디렉터리에는 원본 Codex 펫 이미지가 포함되어 있지 않습니다.

프로그램을 직접 빌드하려면 자신이 사용할 권한이 있는 이미지를 다음 경로에 준비하세요.

```text
assets/spritesheet-keyed.png
```

현재 소스 코드가 기대하는 규격은 다음과 같습니다.

- 전체 크기: `1536 × 2288px`
- 프레임 셀 크기: `192 × 208px`
- 배열: 가로 8칸 × 세로 11칸
- 이미지 형식: PNG
- 투명 영역의 색상 키: 정확한 마젠타 `#FF00FF`

프로그램은 실행할 때 스프라이트 전체를 포함하지 않고, 필요한 셀을 `141 × 153px` 크기의 투명 펫 창에 맞춰 그립니다. 프레임의 행과 순서가 다르면 상태별 애니메이션이 올바르게 표시되지 않습니다.

`.gitignore`가 PNG와 WebP 파일을 제외하도록 설정되어 있으므로, 개인적으로 준비한 스프라이트가 실수로 GitHub에 올라가지 않습니다.
