# Codex Pet Walker

Codex 데스크톱 앱의 플로팅 펫을 화면 안에서 산책시키는 비공식 Windows 보조 프로그램입니다.

이 저장소는 프로그램의 작동 구조를 보여주기 위한 **소스 코드 공개본**입니다. 원본 Codex 설치 파일을 수정하지 않으며, Codex 펫 스프라이트와 빌드된 실행 파일은 포함하지 않습니다.

## 어떤 식으로 작동하나요?

1. 실행 중인 Codex의 원본 펫 창을 Windows 창 정보로 찾습니다.
2. 원본 창을 잠시 숨기고, 같은 위치에 투명한 WinForms 창을 표시합니다.
3. 별도의 업데이트 루프가 대기·산책·드래그·작업 상태에 맞는 스프라이트 프레임을 재생합니다.
4. 화면의 작업 영역 안에서 목적지와 휴식 시간을 무작위로 정해 펫을 움직입니다.
5. 펫을 클릭하면 원본 Codex 창을 앞으로 가져옵니다.
6. 프로그램을 정상 종료하면 숨겼던 원본 펫 창을 다시 표시합니다.

Codex 작업 상태는 사용자 컴퓨터의 `%USERPROFILE%\.codex\sessions` 아래에 기록되는 세션 파일을 로컬에서 확인해 감지합니다. 작업 시작·완료를 나타내는 기록만 읽으며, 네트워크로 파일을 전송하지 않습니다.

## 주요 기능

- 화면 안에서 무작위 산책 및 정지·느리게·보통·빠르게 속도 선택
- 대기, 이동, 클릭, 드래그, 작업 중, 작업 완료 애니메이션
- 작업 시작·진행·완료·결과 확인 대기 말풍선
- 실제 작업 상태를 방해하지 않는 `작업하는 척 하기` 시험 기능
- 펫 클릭 시 Codex 창 활성화
- Windows 로그인 시 Codex와 함께 자동 실행
- 도우미 종료 또는 비정상 종료 후 원본 펫 복원

## 폴더 구성

```text
src/CodexPetWalker.cs       프로그램 소스 코드
tools/restore-native.ps1    숨겨진 원본 펫을 복원하는 도구
assets/README.md            필요한 스프라이트 규격 설명
build.ps1                   Windows용 빌드 스크립트
RELEASE_NOTES.md            버전별 변경 기록
```

## 빌드 준비

이 공개본에는 Codex 펫 이미지가 포함되어 있지 않습니다. 직접 사용할 권한이 있는 스프라이트를 `assets\spritesheet-keyed.png`라는 이름으로 준비해야 합니다. 자세한 규격은 [assets/README.md](assets/README.md)를 참고하세요.

준비가 끝났다면 Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
.\build.ps1
```

Windows에 기본 포함된 .NET Framework C# 컴파일러를 사용합니다. 빌드 결과는 `dist\CodexPetWalker.exe`와 `dist\spritesheet.png`로 만들어집니다.

## 주의 사항

- Windows 및 Codex 데스크톱 앱의 현재 창 구조에 맞춰 만든 개인 프로젝트입니다. Codex 업데이트에 따라 동작하지 않을 수 있습니다.
- 특정 펫 스프라이트의 프레임 배열에 맞춰져 있어 다른 펫에는 그대로 적용되지 않을 수 있습니다.
- 자동 실행 옵션을 켜면 현재 사용자 레지스트리의 `Run` 항목을 사용합니다.
- OpenAI의 공식 제품이나 공식 배포물이 아닙니다.

## 저작권과 라이선스

Codex 펫 스프라이트와 그 파생 이미지는 이 저장소에 포함하지 않습니다. 해당 이미지의 권리는 원 권리자에게 있습니다.

현재 소스 코드에는 별도의 오픈 소스 라이선스를 지정하지 않았습니다. 따라서 공개된 코드는 구조를 열람하고 참고하기 위한 것이며, 복사·재배포·상업적 이용 허용을 의미하지 않습니다. 추후 재사용을 허용하려면 별도의 라이선스를 선택해 추가해야 합니다.
